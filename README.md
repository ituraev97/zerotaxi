# ZERO TAXI — лендинг для подключения водителей

Одностраничный сайт таксопарка **ZERO TAXI** (Ташкент), официального партнёра Yandex Go.
Цель страницы — заявки от водителей на подключение к парку.

## Что внутри

```
index.html      весь сайт: HTML + CSS + JS в одном файле, без фреймворков и сборщика
uploads/        логотип и знак в SVG + разбор фирменного стиля (README-brand.md)
netlify.toml    конфиг деплоя (без сборки, публикуется корень)
robots.txt      разрешает индексацию
```

## Деплой на Netlify

Сборка не нужна. В Netlify: **Add new site → Import from Git → этот репозиторий**.
Build command оставить пустым, publish directory — корень (`.`). Это уже прописано в `netlify.toml`.

Форма заявки работает через **Netlify Forms**: у формы есть `data-netlify="true"`,
скрытое поле `form-name` и honeypot `bot-field`. Заявки появятся в разделе
**Forms** в панели Netlify сразу после первого деплоя. Уведомления на почту
включаются там же: Forms → Settings → Form notifications.

## Как править содержимое

### Калькулятор заработка

Все константы — в объекте `CONFIG` в начале `<script>` в `index.html`:

```js
var CONFIG = {
  avgSpeed: 22,              // средняя скорость по Ташкенту, км/ч
  tariffs: {
    start:    { name:'Старт',    perKm: 970,  perMin: 415, util: 0.65 },
    comfortP: { name:'Комфорт+', perKm: 2120, perMin: 590, util: 0.55 },
    business: { name:'Бизнес',   perKm: 2800, perMin: 700, util: 0.50 }
  },
  boost: 1.2,                // коэффициент витрины: 1.0 = честные цифры, 1.2 = +20%
  demand: { normal:{k:1.0}, rush:{k:1.3}, night:{k:1.2}, high:{k:1.6} },
  yandexFee: 0.185,          // комиссия Яндекса
  parkFee:   0.025,          // комиссия ZERO TAXI
  weeksInMonth: 4.33
};
```

Формула:

```
за час   = (avgSpeed × perKm + 60 × perMin) × util × коэффициент спроса × boost
за смену = за час × часов
на руки  = за смену − комиссия Яндекса − комиссия парка
за неделю = на руки × дней
за месяц  = за неделю × weeksInMonth
```

Проценты комиссий в подписях подставляются из `CONFIG` автоматически —
менять текст руками не нужно.

При настройках по умолчанию (Комфорт+, 10 ч, 6 дней, обычный день):
541 000 грязными → 427 000 на руки за смену → 2 562 000 в неделю → 11 093 000 в месяц.

**`boost: 1.2`** поднимает все суммы на 20% относительно расчёта по тарифам.
Чтобы показывать честные цифры — поставьте `boost: 1.0`.

### Тексты и второй язык

Русский текст лежит прямо в разметке. Узбекский — в объекте `UZ` в `<script>`,
ключ совпадает с атрибутом `data-i18n` у элемента. Переключение RU/UZ без
перезагрузки, язык по умолчанию — русский.

Добавляете новый текст → ставите элементу `data-i18n="ключ"` и дописываете
`ключ:'...'` в `UZ`.

### Контакты

Телефон, Telegram, почта и адрес встречаются в нескольких местах: в секции
«Заявка», в футере, в плавающей кнопке и в микроразметке `application/ld+json`
в `<head>`. При смене контактов проверьте все — проще всего поиском по файлу
(`+998974035151`, `zerotaxiplus`).

## Что осталось сделать после привязки домена

- `<link rel="canonical">` и `<meta property="og:url">` с реальным адресом;
- `og:image` — сейчас указан SVG-логотип, нужно реальное фото парка 1200×630 (JPG/PNG);
- `sitemap.xml` и ссылка на него в `robots.txt`;
- узбекская версия переключается скриптом и отдельно не индексируется. Для SEO
  на узбекском нужна отдельная страница `/uz` с `hreflang`.

## Фотографии

Фотографий на странице нет — все фоновые блоки собраны на CSS-градиентах в цветах
логотипа (бирюзовый / жёлтый / чёрный). Внешних запросов за картинками страница
не делает, грузится быстро. Если позже появятся фото парка, заменяются блоки
`.hero__bg`, `.req__banner` и `.oil__art` в CSS.

## Совместимость и доступность

- Mobile-first, брейкпоинты 1120 / 900 / 520 px.
- Semantic HTML, `aria-*` у интерактивных элементов, видимый focus для клавиатуры.
- `prefers-reduced-motion: reduce` отключает все анимации.
- Без JS страница остаётся полностью читаемой: скрытие секций для анимации
  появления навешивается скриптом, а не зашито в разметку.
