# ZERO TAXI — разбор логотипа

## Цвета

| Роль | HEX | RGB |
|---|---|---|
| Бирюзовый тёмный | `#43AAB6` | 67, 170, 182 |
| Бирюзовый светлый | `#4FB5B9` | 79, 181, 185 |
| Жёлтый тёмный | `#FDC446` | 253, 196, 70 |
| Жёлтый светлый | `#FECF5A` | 254, 207, 90 |
| Текст | `#111111` | 17, 17, 17 |
| Галочка «verified» | `#1D9BF0` | 29, 155, 240 |

Жёлтая пара — один тон: HSL 41,6° / 98% / L 63% → L 68%.
Бирюзовая пара чуть «плывёт» по тону (187° → 182°).

## Геометрия знака

Знак построен на ромбической сетке:

- сторона ячейки ≈ 31,3 (в координатах исходника 640×640);
- базисные векторы `p = (20,36; −23,77)`, `q = (7,07; 30,49)`, угол между ними 126,4°;
- силуэт = 14 ячеек, поворотная симметрия 180°;
- молния = вырез из 3 ячеек;
- каждая ячейка делится по диагонали `p+q`: верхний треугольник — тёмный оттенок, нижний — светлый.

Габарит знака: 130,2 × 145,8 (соотношение 0,893 — знак выше, чем шире).

**Известное отклонение:** верхне-правый ромб бирюзовой половины залит тёмным целиком,
хотя по общему правилу его нижняя половина должна быть светлой. В зеркальном ромбе
жёлтой половины правило соблюдено. В файлах сохранено как в оригинале.

## Шрифт

Геометрический гротеск, круглые овалы, одноэтажная `a`, бесточечная `ı` в «Taxı».

| | Значение |
|---|---|
| Высота прописных (Zero Taxı) | 69 |
| x-height | 44 (0,64 от прописной) |
| Толщина штриха | 6,5 (Light / Book) |
| Высота прописных подписи | 21 (30% от основного) |

Ближайший коммерческий — **Century Gothic**.
Бесплатные замены: **Poppins Light**, **Jost Light**, **Questrial**.

В поставленных файлах текст переведён в кривые — шрифт для рендера не нужен.

## Пропорции локапа

- знак и текст выровнены по общей оптической линии;
- отступ от знака до буквы «Z» ≈ 0,16 от высоты знака;
- подпись отцентрована под вордмарком.
